- Spike filter of E2 (`export_wind_sim.py --meas-spike-hold 5`): causal; a measured sample whose horizontal step from the
  last accepted value exceeds 5 m/s (the spike definition of REGISTER_P2 sec 36) is replaced by that value, at most 2
  samples in a row (a real step is then accepted). Only the measurement changes, never w_plant.
- **Fair headline, reported beside the old one:** PAW-MOBADC against MOBADC-W (both use the wind sensor) - from the
  ablation columns already run (D2 / TAB tables), no new column.
- Adding PAW columns to a TAB table applies the one-set rule over all its columns (a segment on which a PAW column
  stops leaves the whole table); the paper states the set of each table.
